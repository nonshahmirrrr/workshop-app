# Car Workshop Management System

A full stack web application for managing a car workshop built with Flask and MySQL.

## Features
- Customer management
- Vehicle tracking
- Service management
- Mechanics management
- Parts and inventory tracking
- Billing system
- Service records
- User authentication

## Tech Stack
- Python
- Flask
- MySQL
- HTML/CSS

## How to Run
1. Clone the repository
2. Install dependencies: `pip install flask mysql-connector-python`
3. Set up MySQL database
4. Run `python app1.py`
5. Open `http://localhost:5000` in your browser
